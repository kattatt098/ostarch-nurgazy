MacBook Air (M1, 2020) — Component Analysis
Source: Apple Repair Manual, MacBook Air (M1, 2020), Exploded View and Orderable Parts, pp. 6–7.
1. Bottom case
What: The bottom case is the outer cover on the underside of the MacBook. It protects the internal components.
Connects to: Attaches to the top case using screws.
Limits: It provides physical protection but does not contain the main computing components. It must be removed to access internal parts.

2. Embedded DisplayPort (eDP) connector cowling
What: A small protective cover over the display cable connector.
Connects to: Covers and secures the eDP connector on the logic board.
Limits: It does not carry the display signal itself. It protects the connector and must be removed carefully during display cable service.

3. Embedded DisplayPort flex cable with connector cowling
What: A flexible cable that carries display signals.
Connects to: Connects the display assembly to the logic board.
Limits: The cable is thin and delicate. It can be damaged by bending or pulling it incorrectly. It is not a general-purpose upgrade component.

4. Audio board/speaker/Touch ID board connector cowling
What: A protective cover that holds several internal cable connections in place.
Connects to: Covers the connectors for the audio board, speakers, and Touch ID board flex cables.
Limits: It is not an electronic board and does not process signals. Its purpose is to protect and secure the connectors.

5. Logic board
What: The main circuit board of the MacBook. It contains the Apple M1 system-on-a-chip and connects the major hardware components.
Connects to: Connects with the display, battery, audio board, speakers, Touch ID board, trackpad, antenna module, and input/output board.
Limits: The CPU and unified memory are integrated into the M1 platform and cannot be upgraded separately. The internal storage is not designed for a standard user-performed upgrade. Logic board replacement requires specialized service procedures.

6. Audio board flex cable

- What: A flexible cable that carries audio signals and connects the audio board to the logic board.
- Connects to: Connects the audio board with the logic board.
- Limits:It is a thin, delicate cable. It cannot be upgraded and may stop audio functions from working if damaged.

7. Battery

- What: The battery supplies electrical power to the MacBook when it is not connected to a charger.
- Connects to: Connects to the logic board through a battery connector.
- Limits: It has a limited charge cycle lifespan. It is glued inside the case and requires careful removal. It is not designed for a simple user replacement.

8. Speakers
- What: Internal speakers that convert audio signals into sound.

- Connects to: The audio system through the internal speaker connectors and logic board.

- Limits: Fixed internal components; they cannot be expanded or upgraded like external audio devices.

9. Audio board
- What: A dedicated internal circuit board that provides audio-related connections and functions.

- Connects to: The logic board through the audio board flex cable and to the internal audio components.

- Limits: It is a model-specific board, not a general-purpose expansion slot. It cannot be used to add other hardware.


10. Touch ID board

- What: The board associated with the Touch ID sensor and power button.
- Connects to:Connects to the logic board through an internal flex cable.
- Limits: The Touch ID sensor is security-related and replacement may require Apple's authorized service and configuration procedures.

11. Input device flex cable

- What: A flexible cable that carries signals from the keyboard and other input devices.
- Connects to:Connects the input devices in the top case to the logic board.
- Limits: It is thin and delicate. Damage can affect keyboard input and other input functions.

12. Trackpad

- What: The trackpad is the touch-sensitive surface used to control the pointer and perform gestures.
- Connects to:Connects to the logic board through an internal flex cable.
- Limits: It has a fixed physical size and cannot be upgraded like a removable computer component.

13. Antenna module

- What: The antenna module sends and receives wireless signals.
- Connects to: Connects to the wireless communication system on the logic board through antenna cables.
- Limits: Its performance depends on antenna placement and the laptop's physical design. It is not a user-configurable wireless expansion card.

14. Display

- What: The display assembly shows images, text, and video. It includes the screen and related display components.
- Connects to: Connects to the logic board through the eDP flex cable.
- Limits: It has a fixed 13.3-inch size and 2560 × 1600 native resolution. Replacing it requires careful disassembly.

15. Input/output board connector cowling

- What: A protective cover for the input/output board connector.
- Connects to: Covers and secures the connector between the input/output board and its flex cable.
- Limits: It does not transmit data or provide ports itself. Its purpose is connector protection and retention.

16. Antenna connector cowling

- What: A protective cover for the antenna connectors.
- Connects to: Covers and secures the antenna connections on the logic board.
- Limits: It does not receive or transmit wireless signals. It only protects and holds the connectors.

17. Input device connector cowling

- What: A protective cover for the input device cable connector.
- Connects to: Covers and secures the input device flex cable connection to the logic board.
- Limits: It does not process keyboard or input signals. It protects the connector from accidental movement or damage.

18. Input/output board

- What: A small circuit board that provides external input and output connections.
- Connects to: Connects to the logic board through an internal flex cable.
- Limits: It has a fixed set of ports and cannot be expanded like a desktop motherboard.

19. Top case with keyboard

- What: The main upper enclosure of the MacBook, including the keyboard and the surrounding structure.
- Connects to: Forms the upper enclosure and supports the keyboard and other components installed in the top case. Its input-device connections link it to the logic board.
- Limits: It has a fixed design and layout. Replacing it involves transferring or servicing several internal components.
